# How to run this program:
- Clone my repo as shared with you, and run npm i to install the dependencies.
- use npm run dev, to run the index.ts file(our main code file) directly;
- As for production(.js file) you can do npm run build to transpile ts code into js code
inside dist/index.js file.
- to run the index.js file, do , npm run start
- Now,run, npm run dev , follow the input protocol as shared by you guys(Move to the next line of input by pressing enter). After you finish with the input, move to the next line and press
CTRL+D(this basically lets the program know that the user is finished with the input);

# Assumptions I made for this assignment:
- Plateau and Robot cordinates are +ve integers.
- As stated, only uppercase 'L' 'R' and 'M' are valid commands/instruction for movement/rotation
- Robots will stay at their place if their next step take them outside plateau boundary.
